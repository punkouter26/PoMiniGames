3. Middleware order & the /_framework anonymous opt-out

The order matters: any middleware that touches Response.Body before UseResponseCompression() bypasses compression for that response. UseAuthentication must precede UseAuthorization precedes app.MapPoMiniGamesEndpoints() precedes the typed /api/{*rest:nonfile} 404 handler precedes the SPA fallback.

  1. UseResponseCompression() — first to wrap every later body write.
  2. UseCors("PoMiniGamesDevSpa") — Dev-only; CORS preflight must answer before auth.
  3. UseMiddleware<RequestLogContextMiddleware>() — sets UserId/SessionId log enrichers.
  4. UsePoMiniGamesRequestLogging() — Serilog request logger.
  5. UseExceptionHandler() + UseHsts() (non-dev) or dev exception handler.
  6. MapOpenApi() + MapScalarApiReference(...) (Purple theme) — unauthenticated.
  7. Dev-only no-cache middleware for the SPA shell + /_framework/*.
  8. UseBlazorFrameworkFiles().
  9. appsettings gate — serves the client's appsettings.json (never the server's), allow-listed to two filenames.
  10. /_framework/*.pdb 204 handler — the "anonymous opt-out" the prompt asks about. Production builds don't ship .pdb symbols but blazor.boot.json still references them by SRI hash, so the browser logs "Failed to find a valid digest" on every boot. The handler returns 204 for any /_framework/*.pdb request, keeping the boot manifest honest without serving stale content.
  11. UseStaticFiles(...) — Vary: Accept-Encoding, Content-Length removed, IHttpResponseBodyFeature swapped to StreamResponseBodyFeature so the WASM payload goes through the compression stream instead of SendFile.
  12. UseAuthentication() — JWT, DevCookie, FakeAuth (Composite policy).
  13. UseRateLimiter().
  14. UseAuthorization().
  15. app.MapPoMiniGamesEndpoints() — all routes + hubs.
  16. app.Map("/api/{*rest:nonfile}", () => Results.NotFound(...)) — typed 404 JSON so the SPA fallback below cannot silently return HTML for an unknown /api/* path.
  17. app.MapFallbackToFile("index.html") — SPA shell for extensionless client routes.

Why the /_framework/*.pdb opt-out exists

Bug-fix QA #10 in Program.cs: production blazor.boot.json references _framework/Po*.pdb by SRI hash, but the published build never carries those symbols. Returning 204 makes the boot manifest happy without serving stale or fictional content. The handler is anonymous (no auth) because the browser needs to fetch it during the very first paint, before any auth round-trip.

4. Request flow — typical multi-player turn

Step 1–2 are the SignalR negotiate + WebSocket upgrade with ?access_token=... (the prompt requires the token for the WS upgrade specifically because browsers can't send custom headers on a WS). Step 3 is the policy scheme forwarding to JWT Bearer. The 401 / 429 / 5xx failure surfaces are deliberate — see Report 8 for the full user-workflow trace.

5. Single registration point contract

Verdict · every route & hub lives in one place

src/PoMiniGames/Infrastructure/EndpointRouteExtensions.cs is the only file in the solution that calls app.MapGroup(...), app.MapGet/MapPost(...), or app.MapHub<T>(...) on the host. Program.cs then invokes app.MapPoMiniGamesEndpoints() as a single ordered call. The pattern is enforced by convention and code review, not by a unit test (no equivalent of TestCountCeilingTests exists for route placement).
