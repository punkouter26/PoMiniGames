User workflow report

Audit of the request lifecycle from UI submit through the Minimal API / SignalR hub through orchestration through Azure Tables persistence. Every step cites a file path; nothing is assumed.

There is no queue and no orchestrator

PoMiniGames is request/response and hub-broadcast. There is no Azure Service Bus, no Queue-triggered worker, no orchestrator pattern; the "PoSurvive simulation" runs in-process inside Application/Services/, not as a queued background job. Persistence is synchronous against Azure Table Storage (or Azurite locally).

3. Failure surfaces

3.1 401 — unauthenticated

Cookie auth events override the framework's default redirect-to-login behaviour: an unauthenticated /api/* call returns 401 Unauthorized, not 302 Found. The SPA's ApiService translates the 401 into AuthHandshakeReauthRequiredException or a normal "needs login" path. AuthStateService deduplicates concurrent /api/auth/handshake calls so a navigation race doesn't flood the wire.

3.2 429 — rate limited

The rate-limiter is configured with RejectionStatusCode = 429. Policies: highscores (10/min), infer (10/sec), ai-generation (5/min), face-analysis (2/10sec — declared but no endpoint uses it). Compound partition = {ip}|{identity-or-anon} so anonymous bursts don't poison authenticated buckets.

3.3 Provider retry

Every AI consumer uses the same resilience pipeline via AddAzureOpenAIResilience(): retry + circuit breaker + outer timeout. There is no project-level "max retries" knob; it's whatever the standard resilience handler ships with. PoJoker uses AddStandardResilienceHandler() on its JokeApiClient HttpClient (15 s timeout).

3.4 Save retry

Azure Tables does Add for new rows and Upsert for updates. A concurrent create surfaces as 409 Conflict; TableConcurrency.cs retries with re-read on 409. No application-level retry loop wraps SaveXxxHighScoreAsync itself — the SDK handles it.

3.5 Mock banner

The SPA shows a mock banner whenever AuthStateService.UsingMockData is true (i.e. FeatureFlags:UseMockData is true). The same flag drives per-game IsMock surfaces on services that implement IMockable; /api/mockables enumerates them and is hidden (404) in Production.

3.6 Handshake transport abort

When the SPA navigates mid-handshake, the browser aborts the in-flight /api/auth/handshake with ERR_ABORTED. AuthStateService treats this as "still warming up" and keeps the previous identity rather than blanking the header. The next page mount retries the call.
